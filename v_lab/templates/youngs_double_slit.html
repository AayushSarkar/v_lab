Aim

To understand the interference pattern formed by light passing through two slits, and to calculate the fringe width.

Theory

In Young's Double Slit experiment, light passing through two slits creates an interference pattern on a screen. This occurs due to the constructive and destructive interference between the light waves passing through the slits.

Fringe width formula: β = λD / d, where:

  • λ = Wavelength of light
  • D = Distance from slits to screen
  • d = Distance between the slits

Procedure

  1. Setup the Experiment: Ensure the virtual lab is loaded with adjustable parameters for wavelength, slit separation, and screen distance.
  2. Adjust Wavelength (λ): Select the desired wavelength using the Wavelength slider, ranging from 400 nm (violet) to 700 nm (red).
  3. Adjust Slit Separation (d): Use the Slit Separation slider to adjust the distance between the slits.
  4. Adjust Distance to Screen (D): Set the distance to the screen using the Distance to Screen slider.
  5. Observe the Interference Pattern: After adjusting, observe the interference pattern formed on the virtual screen.
  6. Measure Fringe Width (β): The fringe width is calculated based on the selected parameters, displayed in millimeters.
  7. Experiment with Different Values: Adjust parameters and observe how the fringe pattern changes.
  8. Record the Results: Record the fringe width for each combination of parameters.
  9. Analyze and Conclude: Analyze your observations and compare them with theoretical predictions.

Observation

As the parameters change, you will observe variations in the interference fringes. Wider wavelengths lead to wider fringes, and closer slit separations lead to more pronounced patterns.

Result

The simulated fringe width β will match the theoretical results, calculated using the formula β = λD / d. This allows you to verify your results.
